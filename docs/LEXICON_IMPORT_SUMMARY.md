## 🔍 关键技术发现

### 1. 架构发现

**MMS系统直接使用原系统词表**:
- 表名: `nlp_medical_dict`, `nlp_phrase_map`, `nlp_ambiguity`
- 结论: 无需数据迁移，只需补充缺失词汇
- 优势: 数据一致性高，维护成本低

### 2. 词汇与标准库的关系

**关键insight**:
```
新增词汇 ≠ 立即提升匹配率

原因: 词汇识别 + 标准库匹配 = 最终结果

示例:
  输入: "经皮穿刺乳腺活检"
  词汇: ✅ 能识别（新增"穿刺"、"活检"）
  标准: ❌ 无此标准项（标准库只有"血管造影"）
  结果: ❌ 仍然无法匹配
```

**结论**: 
- 补充词汇是**必要条件**，但非**充分条件**
- 要提升匹配率，词汇和标准库**缺一不可**

### 3. 标准库现状

**DSA模态** (28个标准项):
- ✅ 有: 血管造影类（主动脉、脑血管、肾动脉等）
- ❌ 缺: 介入操作类（穿刺、活检、导管置入、栓塞等）
- 影响: 161条DSA失败案例，大部分是介入操作类

**SPECT模态** (48个标准项):
- ✅ 有: 显像类（亲肿瘤、心肌灌注、骨显像等）
- ⚠️ 问题: PET/CT混在SPECT中，需要独立分类

**RF模态** (少量标准项):
- ✅ 有: 肾盂穿刺造影等
- ❌ 缺: 大部分造影类标准项

**US模态** (大量标准项):
- ✅ 覆盖全面，词汇补充后效果最好

## 🎓 关键经验

### 成功要素

1. **数据共享架构** - 避免复杂迁移
2. **失败分析驱动** - 针对性补充词汇
3. **分模态策略** - 不同模态采用不同方案
4. **小步快跑** - 74条词汇分批导入测试

### 技术教训

1. **词汇≠匹配率**
   - 词汇只是第一步
   - 标准库缺失会限制效果
   - 需要词汇+标准库双管齐下

2. **验证先于补充**
   - 补充词汇前，先确认标准库覆盖
   - DSA的介入词汇虽然补充了，但标准库缺失导致效果有限

3. **算法优化 > 词汇补充**
   - DR的71条失败，词汇全部存在
   - 瓶颈在算法无法处理复杂表述
   - 需要算法层面的优化

### 工作流程

```
1. 失败分析 → 识别瓶颈模态
2. 原因诊断 → 区分"缺词"vs"缺标准"vs"算法限制"
3. 针对性方案 → 补充词汇/标准库/优化算法
4. 小批量测试 → 验证效果
5. 全量部署 → 重新评测
```
