#### 2. 统一部位字典映射 ✅
**问题描述**:
- 引擎归一化: `盆腔` → `盆腔及盆底结构`
- 标准库字段: `body_part_l2 = '盆腔'`
- 结果: 部位对不上，即使扫描方式匹配也查不到

**解决方案**:
1. 新增 `BODY_PART_EQUIVALENTS` 映射表
2. `StandardLookupService._expand_body_equivalents()` 方法
3. 应用到所有查询方法（`_query_ct_mr/_query_dr/_query_rf_mg`）

**映射关系**:
```python
盆腔 ↔ 盆腔及盆底结构
四肢 ↔ 四肢及关节 ↔ 关节
颅脑 ↔ 脑 ↔ 头颅
全腹部 ↔ 腹部
```

**测试结果**:
- ✅ 部位等价映射表测试 3/3 通过
- ✅ 部位扩展方法测试 5/5 通过

**影响**: 
- 放大 P1 扫描组合降级的效果
- 消除部位命名不一致导致的匹配失败

**提交**: `8b00877` - feat(P2): 统一部位字典映射
