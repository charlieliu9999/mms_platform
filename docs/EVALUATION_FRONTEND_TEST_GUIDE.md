# 评测系统前端测试指南

## 服务状态

- ✅ **后端**: http://localhost:9100
- ✅ **前端**: http://localhost:3101
- ✅ **API 文档**: http://localhost:9100/docs

## 测试流程

### 1. 访问评测系统

打开浏览器访问：http://localhost:3101/evaluation

应该看到：
- 4个统计卡片（总任务数/已完成/执行中/待执行）
- 评测任务列表
- "创建任务" 和 "刷新" 按钮

### 2. 创建评测任务

1. 点击 "创建任务" 按钮
2. 填写表单：
   - **任务名称**: CT项目快速测试
   - **任务描述**: 测试50条CT数据
   - **测试文件路径**: tests/benchmark/16zzy_ct_115k.csv
   - **采样数量**: 50
   - **模态过滤**: CT
   - **创建人**: 你的名字
3. 点击 "创建任务"
4. 应该自动跳转回任务列表

### 3. 启动评测

1. 在任务列表中找到刚创建的任务（状态：待执行）
2. 点击 "启动" 按钮
3. 观察状态变化：
   - 状态变为 "执行中"
   - 进度条显示百分比
   - 每2秒自动刷新进度
   - 约5-10秒后完成

### 4. 查看评测结果

1. 任务完成后，点击 "详情" 按钮
2. 查看任务信息：
   - 基本信息（ID/状态/进度/测试总数等）
   - 4个核心指标卡片（匹配率/准确率/F1/响应时间）
   - 失败案例表格（支持分页）
   - 失败原因统计

### 5. 分析失败案例

切换到 "失败案例" 标签页：
- 查看每个失败案例的详细信息
- 期望结果 vs 实际结果对比
- 失败原因标签（缺少词汇/存在歧义/复杂表述等）

切换到 "失败原因统计" 标签页：
- 查看各类失败原因的数量分布
- 用于优化决策（优先解决哪类问题）

### 6. 删除测试任务

1. 返回任务列表
2. 点击任务的 "删除" 按钮
3. 确认删除

## 预期结果

### 正常指标范围

- **匹配率**: 95-100% ✅
- **准确率**: 75-85% ⚠️（编码版本差异导致）
- **F1分数**: 75-85%
- **平均响应时间**: 15-25ms ⚡
- **平均置信度**: 9.5-10.0 💯

### 常见失败原因

1. **wrong_match** (错误匹配)
   - 名称相似但不完全匹配
   - 例如："中下腹部" vs "中腹部"

2. **no_standard** (无标准项)
   - 复杂复合项目
   - 例如："CT增强扫描(下颌骨)(单次多层螺旋CT),CT增强扫描(下颈部)..."

3. **missing_word** (缺少词汇)
   - 词表中没有的罕见术语

4. **complex** (复杂表述)
   - 超长项目描述
   - 多层嵌套结构

## 故障排查

### 问题1: 前端无法连接后端

**症状**: API 请求失败，Console 显示网络错误

**解决方案**:
```bash
# 检查后端是否运行
curl http://localhost:9100/docs

# 如果未运行，启动后端
poetry run uvicorn match_service.main:app --reload --port 9100
```

### 问题2: 创建任务失败（测试文件不存在）

**症状**: 提示 "测试文件不存在"

**解决方案**:
- 确认测试文件路径正确
- 路径相对于项目根目录
- 正确示例: `tests/benchmark/16zzy_ct_115k.csv`

### 问题3: 评测执行失败

**症状**: 任务状态变为 "失败"

**解决方案**:
1. 检查后端日志
2. 确认数据库连接正常
3. 确认引擎已初始化
4. 检查测试文件格式是否正确

### 问题4: 进度卡住不更新

**症状**: 进度条停留在某个百分比不动

**解决方案**:
- 刷新页面
- 手动点击 "刷新" 按钮
- 检查后端日志是否有异常

## API 端点测试（使用 Postman 或 curl）

### 创建任务
```bash
curl -X POST http://localhost:9100/api/evaluation/tasks \
  -H "Content-Type: application/json" \
  -d '{
    "name": "API测试",
    "test_file_path": "tests/benchmark/16zzy_ct_115k.csv",
    "sample_size": 30,
    "modality": "CT"
  }'
```

### 启动评测
```bash
curl -X POST http://localhost:9100/api/evaluation/tasks/1/start
```

### 查询任务
```bash
curl http://localhost:9100/api/evaluation/tasks/1
```

### 查询失败案例
```bash
curl "http://localhost:9100/api/evaluation/tasks/1/failures?limit=10"
```

### 查询失败统计
```bash
curl http://localhost:9100/api/evaluation/tasks/1/failures/stats
```

## 已知问题

1. **编码版本差异**
   - 测试数据使用 V3.8.2 编码
   - 数据库使用不同版本编码
   - 导致准确率计算偏低
   - **不影响实际使用**（名称匹配正确）

2. **前端轮询机制**
   - 当前使用简单的定时轮询
   - 未来可改用 WebSocket 实时推送

3. **大数据量性能**
   - 10万+数据评测需要较长时间
   - 建议分批执行或使用采样
