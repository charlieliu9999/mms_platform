## 优化策略

### Phase 1: P1算法修复（立即实施，预计挽回19-22项）

根据 `docs/ct-mr-unmatched-algorithm-analysis.md` 分析：

#### 1.1 扫描组合降级（预计挽回~19项）
**问题**：`MR颅脑(平扫+DWI)` 类医嘱无法匹配，因为标准库中 `平扫+DWI` 组合项极少（仅1条）。

**修复位置**：`src/match_service/engine/match_engine_v2/standard_lookup_service.py` 的 `_query_ct_mr()` 方法

**实现逻辑**：
```python
# 当 scan 值含 '+' 且精确匹配为空时
if '+' in scan_str and matched.empty:
    # 拆分为分量：'平扫+DWI' → ['平扫', 'DWI']
    components = scan_str.split('+')
    # 展开缩写：'DWI' → '弥散加权成像(DWI)'
    expanded = [expand_abbreviation(c) for c in components]
    # 降级查询
    mask = df['three_level_name'].isin(bodies) & df['scan_name'].isin(expanded)
    degraded_match = df[mask]
    if not degraded_match.empty:
        return degraded_match, True  # 标记为 degraded
```

**缩写映射表**：
- `DWI` → `弥散加权成像(DWI)`
- `DCE` → `动态对比增强(DCE-MRI)`
- `CTU` → `尿路造影成像(CTU)`
- `MRS` → `磁共振波谱(MRS)`
- `PWI` → `灌注加权成像(PWI)`

#### 1.2 方括号修饰语拆分Bug（预计挽回~3项）
**问题**：`MR面神经[颅外段](平扫)` 的标准项在库中存在，但方括号内容被拆分成独立 body 节点导致 ambiguous。

**修复位置**：`src/match_service/engine/match_engine_v2/preprocess_service.py` 的 body 拆分逻辑

**临时方案**：在 lookup 阶段容错处理
**长期方案**：修改预处理逻辑，保留方括号修饰语
