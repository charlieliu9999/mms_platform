```python
# 系统的反直觉约定
```

**修复逻辑**:
```python
if soft_col == "is_active":
    delete_value = "false"  # boolean类型
else:
    delete_value = "1"      # enable列（反直觉）
```

## 💡 关键技术亮点

### 1. 双字段兼容设计（B-02）
```python
# 优雅的向后兼容方案
check_item_text = req.text or req.name  # text优先
if not check_item_text:
    raise HTTPException(422, "必须提供 text 或 name 字段")
```

**优点**:
- ✅ 向后兼容旧API（name字段）
- ✅ 支持新前端（text字段）
- ✅ 防御性编程（必填校验）

---

### 2. 类型感知的软删除（B-05, B-03）
```python
# 根据列类型动态选择删除值
if soft_col == "is_active":
    delete_value = "false"  # boolean类型
else:
    delete_value = "1"      # enable列（反直觉）
```

**优点**:
- ✅ 处理不同类型的软删除列
- ✅ 避免硬编码
- ✅ 易于扩展

---

### 3. 元数据驱动的配置（B-03）
```python
RULE_TABLES = {
    "checkitem_standard": RuleTableSpec(
        tablename="standard_check_items",
        soft_delete_col="is_active",
        columns=[...],
    ),
}

# 动态生成WHERE条件
if spec.soft_delete_col == "is_active":
    where_clause = f"{spec.soft_delete_col} = true"
else:
    where_clause = f"{spec.soft_delete_col} = 0"
```

**优点**:
- ✅ 单一真相源（元数据集中定义）
- ✅ 类型安全（根据列类型选择正确的值）
- ✅ 易于维护（新表只需添加元数据）
