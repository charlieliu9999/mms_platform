## 技术实现

### 字段映射策略

原系统 `procedure_dictionary` 字段简单，目标表 `nlp_checkitem_standard` 是ACR标准库结构。主要映射逻辑：

1. **模态映射**: 字符串模态名 → 数字编码（如 'US' → '4'）
2. **部位解析**: 从 `body_part` 文本提取标准部位编码
3. **扫描方式**: 根据 `contrast_used` 和检查名称推断（平扫/增强）
4. **编码生成**: 自动生成 `checkitem_code`（格式：设备类型+部位+扫描方式）

### 数据质量控制

- ✅ 去重逻辑: 检查 `checkitem_name` + `modality_code` 组合是否已存在
- ✅ 版本标记: 所有导入数据标记为 `version='V1.0-imported'`，便于追溯
- ✅ 状态管理: `is_deleted=0`，确保数据激活
- ✅ 时间戳: 记录 `create_time` 和 `update_time`
