## 🔍 根本原因发现

通过对比原系统（acrac_web_mgmt）和新系统（mms_platform），发现：

### ✅ 原系统有模态归一化

**文件**: `acrac_backend/app/services/standardization/modality_extractor.py`

```python
MODALITY_NORMALIZE = {
    'MR': 'MRI',
    'MRI': 'MRI',
}
```

### ❌ 新系统缺少模态归一化

**MMS 项目中**:
- ❌ 没有模态归一化逻辑
- ❌ 只处理了 PET-CT/PET-MR 别名
- ❌ MRI/XR/NM 等常见模态未处理

### 标准库编码方式

MMS 标准库使用**数字代码**:
- `"2"` = CT (7,589条)
- `"3"` = MR (6,326条) ⚠️ **不是MRI**
- `"4"` = X线 (4,752条) ⚠️ **不是XR/DR**
- `"9"` = DSA (28条)

### 匹配失败流程

```
ACR数据: MRI → 匹配引擎 → 查询 "MRI" → ❌ 标准库没有MRI，只有"3"(MR)
ACR数据: XR  → 匹配引擎 → 查询 "XR"  → ❌ 标准库没有XR，只有"4"(X线)
```

**正确流程应该是**:
```
ACR数据: MRI → 归一化为MR → 匹配引擎 → 查询 "3"(MR) → ✅ 找到6326条
ACR数据: XR  → 归一化为DR → 匹配引擎 → 查询 "4"(X线) → ✅ 找到4752条
```
