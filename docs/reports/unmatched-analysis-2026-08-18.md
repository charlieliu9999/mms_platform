## 问题分类

### 1. **复合检查项目 (complex)** - 最普遍的问题

#### 典型案例
```
CTA(头颈),静脉穿刺置管术(影像中心)
CT增强扫描(上腹部)(单次多层螺旋CT),静脉穿刺置管术(影像中心)
CT平扫(肺部)(单次多层螺旋CT),密闭式静脉留置针(影像中心),透明敷料(影像中心)
```

#### 问题根源
- **医院收费系统的组合套餐**，包含多个独立收费项目
- 不是单一标准检查项目
- 混合了：影像检查 + 耗材 + 操作费用

#### 解决方向
1. **预处理拆分**: 识别并提取主要检查项目（去除耗材/操作）
2. **规则增强**: 添加组合项目的解析规则
3. **标记策略**: 标记为"复合项目"，匹配主项目即可

---

### 2. **词库缺失 (missing_word)** - 标准库不完整

#### 典型案例
```
CTA头颈/腹主动脉/下腔静脉（体检中心）
CTU尿路成像(CTA)单次多层CT扫描
64排CT三维（呼吸道仿真内镜）
256排CT肺动脉CTA+肺静脉CTA+肺结节CT分析联合检查
CT-泌尿CT-U造影(双肾、输尿管、膀胱)(含造影剂)
```

#### 问题根源
- 特殊技术/特殊血管组合缺失
- 新技术（CTU、仿真内镜、多血管联合）
- 特殊格式（CT-XXX、多排CT前缀）

#### 解决方向
- **Phase 2**: 补充标准库（168项缺口）
- **Phase 3**: 补充词库映射（70项缺口）

---

## CT模态详细问题

### 血管CTA复合项目问题

#### 问题1: CTA + 静脉穿刺组合
```
CTA(肺动脉),静脉穿刺置管术(影像中心)
CTA(肾动脉),静脉穿刺置管术(影像中心)
CTA(胸主动脉),静脉穿刺置管术(影像中心)
CTA(腹主动脉),静脉穿刺置管术(影像中心)
CTA(颈部),静脉穿刺置管术(影像中心)
CTA(头颈),静脉穿刺置管术(影像中心)
```

**解决方案**: 拆分时过滤掉"静脉穿刺置管术"、"密闭式静脉留置针"、"透明敷料"等耗材/操作项

#### 问题2: CT增强 + 耗材组合
```
CT增强扫描(上腹部)(单次多层螺旋CT),密闭式静脉留置针(影像中心),透明敷料(影像中心)
CT增强扫描(肺部)(单次多层螺旋CT),密闭式静脉留置针(影像中心)
```

**解决方案**: 同上，过滤耗材

#### 问题3: CT + 模拟定位组合
```
CT增强扫描(胸部),复杂模拟定位(CT)
CT增强扫描(下腹部)(单次多层螺旋CT),专用X线机复杂模拟定位
```

**解决方案**: 识别"模拟定位"为放疗相关操作，拆分处理
