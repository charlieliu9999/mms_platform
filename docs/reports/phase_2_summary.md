## Phase 2A: 泛指词汇映射（目标~40项）

### 实施内容
1. 添加 phrase_map 规则（step=normalize）
   - 关节 → 四肢及关节
   - 骨骼 → 全身骨骼
   - 全身 → 全身
   - 血管 → 血管

2. 添加医学词典条目
   - 将"关节""骨骼""全身""血管"加入 nlp_medical_dict

3. 热重载引擎（版本: v15119-143c5b85d10b）

### 测试结果
**通过率**: 2/9 (22%)

### 失败原因分析
**根本问题**：词汇映射方案对泛指部位词汇无效

1. **标准库结构不匹配**：
   - 标准库 body_part_l3 字段存储具体部位（如"双膝关节""双肩关节"）
   - 没有泛指的"关节""骨骼"标准项
   - 即使映射为"四肢及关节"，标准查询也找不到匹配

2. **匹配维度错误**：
   - 词汇映射改变的是实体名称
   - 但标准查找基于 body_part_l3 字段精确匹配
   - 两者不在同一维度

3. **为什么血管成像成功**：
   - "血管成像"被识别为 scan（扫描方式），不是 body
   - 匹配走的是 scan 维度，标准库有对应项

### 结论
**Phase 2A 方案放弃**。需要改用 Phase 4（算法增强），在标准查找阶段实现泛指词汇的降级匹配。

## Phase 2B: 血管成像词汇映射（目标~15项）

### 实施内容
1. 添加 phrase_map 规则（step=global_map）
   - 脊髓动脉 → 脊髓血管
   - 肝脏血管 → 肝脏
   - 小肠血管 → 小肠
   - 肾脏血管 → 肾脏

2. 添加组合词到医学词典
   - 脊髓动脉、脊髓血管、肝脏血管、小肠血管（type=body）
   - 确保 jieba 将它们识别为整体

3. 热重载引擎（版本: v15127-bc5ffebdfb99）

### 测试结果
**通过率**: 4/10 (40%)

成功项目：
- ✅ CT肾脏血管成像(CTA) → exact
- ✅ MR肾脏血管成像(MRA) → exact
- ✅ CT血管成像(CTA) → exact（对照组）
- ✅ MR血管成像(MRA) → exact（对照组）

失败项目：
- ❌ CT脊髓动脉血管成像(CTA) → none
- ❌ MR脊髓动脉血管成像(MRA) → none
- ❌ CT肝脏血管成像(CTA) → none
- ❌ MR肝脏血管成像(MRA) → none
- ❌ CT小肠血管成像(CTA) → none
- ❌ MR小肠血管成像(MRA) → none

### 失败原因深度分析

#### 问题1：Pre规则破坏性替换
数据库中有 pre 步骤规则：
```
血管成像(CTA) → ' CTA'  （注意：dst_word 是空格+CTA）
血管成像(CTV) → ' CTV'
血管成像(CEMRA) → ' CEMRA'
```

**影响**：
- 输入：`CT脊髓动脉血管成像(CTA)`
- Pre规则处理后：`CT脊髓动脉 CTA`
- 结果：body 和 scan 都无法解析，tier=none

**设计初衷**：
- 简化独立的"血管成像(CTA)"表达为" CTA"
- 但对"部位+血管成像(CTA)"复合表达，破坏了语义结构

#### 问题2：标准库部位层级不匹配
标准库结构：
- `body_part_l3`: "颈段脊髓动脉"、"胸段脊髓动脉"、"腰段脊髓动脉"（有节段区分）
- `scan_method`: "CT血管成像CTA"
- `item_name`: "CT颈段脊髓动脉(血管成像CTA)"

用户输入：
- `CT脊髓动脉血管成像(CTA)`（无节段区分，是泛指）

**矛盾**：
- 用户表达是泛指的"脊髓动脉"
- 标准库要求具体节段（颈段/胸段/腰段）
- 即使映射生效，也无法精确匹配

#### 问题3：小肠没有血管成像标准项
查询结果显示：
- 脊髓：有颈段/胸段/腰段脊髓动脉CTA/MRA
- 肝脏：有肝脏动脉MRA
- 肾脏：有肾动脉CTA/MRA（映射成功）
- 小肠：**没有**血管成像标准项（真实的标准库缺口）

### 为什么肾脏成功了
1. 用户输入：`CT肾脏血管成像(CTA)`
2. Pre规则：`血管成像(CTA)` → ` CTA`
3. 处理后：`CT肾脏 CTA`
4. jieba分词：`['CT', '肾脏', ' ', 'CTA']`
5. 引擎识别：body="肾脏", scan="CTA"
6. 标准库有：`body_part_l3="肾动脉"`, `scan_method="CT血管成像CTA"`
7. **关键**：可能有降级匹配逻辑，"肾脏"能匹配到"肾动脉"

但为什么"脊髓动脉"不能匹配到"颈段脊髓动脉"？
- 可能是因为节段词（颈段/胸段/腰段）是必选的，不允许泛指匹配

### 结论
**Phase 2B 部分成功**：
- ✅ 对于标准库有对应项且不需要节段区分的部位（如肾脏），映射有效
- ❌ 对于需要节段区分的部位（如脊髓），无法泛指匹配
- ❌ 对于标准库没有的部位（如小肠血管成像），属于真实的标准库缺口
- ❌ Pre规则的破坏性替换是核心障碍

## 根本问题总结

### 1. Pre规则设计缺陷
`血管成像(CTA)` → ` CTA` 规则过于激进，应该：
- **不删除"血管成像"**，只规范化括号内容
- 或者保留为 `血管成像CTA`（去掉括号）
- 现有设计破坏了"部位+血管成像(CTA)"的语义

### 2. 标准库层级不匹配
- 用户习惯用泛指表达（"脊髓动脉"）
- 标准库要求具体节段（"颈段脊髓动脉"）
- 缺乏泛指→具体的降级匹配机制

### 3. 词汇映射的局限性
- 只能改变实体名称，不能改变匹配逻辑
- 对于结构性问题（部位层级、泛指匹配），需要算法层面的解决方案
