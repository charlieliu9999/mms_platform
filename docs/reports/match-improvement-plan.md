# 4555项目匹配度提升方案

## 一、匹配结果概览

根据对4555项目的匹配分析，发现以下三类主要问题：

1. **标准库缺项（standard_lib_gap）**：医院项目存在但标准库中缺失的检查项目
2. **词库缺项（lexicon_gap）**：术语解析失败，无法提取关键信息
3. **不支持模态（unsupported_modality）**：模态识别错误或不在支持范围内

## 二、问题深度分析

### 2.1 标准库缺项分析

**典型缺失项目特征：**

- **特殊增强方式**：如"CT肝动静脉血管成像(CTA+CTV)"、"CT腹部盆腔(平扫+动静脉双期增强)"
- **特殊造影技术**：如"CT脊柱局部(脊髓造影)"、"CT肩关节(直接造影)"
- **高级成像模式**：如"CT颞骨(超高分辨率UHR模式)"
- **血管专项成像**：如"CT小肠血管成像(CTA)"、"CT肝脏血管成像(CTA)"
- **复合检查**：如"CT 原发部位及区域淋巴结(平扫+增强)"

**问题根源：**
- 标准库覆盖不足，特别是：
  - 复合增强方式（动静脉双期、CTA+CTV组合）
  - 特殊造影技术（直接造影、脊髓造影）
  - 高级技术参数（UHR超高分辨率）
  - 专科特殊检查（原发部位+区域淋巴结）

### 2.2 词库缺项分析

**典型解析失败案例：**

1. **跨模态混淆**：
   - "CT/MRI/PET-CT(化疗前基线)" - 多模态组合
   - "X线 12导联心电图(动态监测)" - 模态标注错误

2. **非影像检查混入**：
   - "X线干血斑串联质谱检测" - 实验室检查
   - "X线心电图(24小时动态心电图)" - 功能检查

3. **介入治疗项目**：
   - DSA系列大量介入操作："DSA经导管动脉栓塞术"、"DSA支气管动脉栓塞术"
   - 血管治疗："DSA腹主动脉-髂动脉支架置入术"、"DSA溶栓/取栓"

4. **口腔专科检查**：
   - "X线口内根尖周片(根尖片)"、"X线曲面体层摄影(全景片)"

**问题根源：**
- 医院项目命名不规范，将模态标识用于非对应检查
- 缺少介入治疗类项目的识别规则
- 缺少口腔、心电等专科检查的排除规则
- 多模态组合检查的解析逻辑缺失

### 2.3 不支持模态分析

**模态分布统计：**
```
OTHER: 408条 (49.9%)
IR: 126条 (15.4%)  - 介入放射
XR: 121条 (14.8%)  - X线（可能误判）
Other: 70条 (8.6%)
SURG: 22条 (2.7%)  - 手术
CBCT: 18条 (2.2%)  - 锥形束CT
ES: 15条 (1.8%)    - 内镜
CT-DE: 14条 (1.7%) - 双能CT
AN: 10条 (1.2%)    - 血管造影
其他: <1%
```

**问题根源：**
- 大量IR（介入放射）项目应纳入DSA或特殊处理
- OTHER和Other占比过高，需要细化分类规则
- CBCT（口腔专用）、ES（内镜）不属于常规影像范畴
- XR中混入了大量心电图、实验室检查

## 三、解决方案

### 方案A：标准库扩充（短期见效）

**优先级1：复合增强方式（预计提升30-50条）**
- 补充"动静脉双期增强"、"CTA+CTV"等组合扫描方式
- 目标项目：
  - CT肝动静脉血管成像(CTA+CTV)
  - CT腹部盆腔(平扫+动静脉双期增强)
  - CT原发部位及区域淋巴结(平扫+增强)
- 实施方式：
  1. 从现有标准库提取"动脉期"、"静脉期"标准项
  2. 创建"动静脉双期"扫描方式词条
  3. 补充消歧规则：`动静脉双期` → `["动脉期", "静脉期"]`
- 预期效果：覆盖20-30%的标准库缺项

**优先级2：特殊造影技术（预计提升10-20条）**
- 补充"直接造影"、"脊髓造影"等特殊造影方式
- 目标项目：
  - CT脊柱局部(脊髓造影)
  - CT肩关节(直接造影)
  - MR肩关节(直接造影)
- 实施方式：
  1. medical_dict 添加："脊髓造影"、"直接造影"
  2. phrase_map 映射到标准扫描方式
  3. 在标准库中添加对应组合项目
- 预期效果：覆盖专科特殊检查10-15%

**优先级3：血管专项成像（预计提升15-25条）**
- 补充各器官的血管成像标准项
- 目标项目：
  - CT小肠血管成像(CTA)
  - CT肝脏血管成像(CTA)
  - CT腹腔血管成像(CTA)
- 实施方式：
  1. 检查标准库是否已有"XX部位+血管成像"组合
  2. 缺失部位补充到 nlp_checkitem_standard
  3. 确保"血管成像"映射到正确的扫描方式
- 预期效果：覆盖血管专项检查15-20%

### 方案B：词库补充与规则优化（中期见效）

**B1：非影像检查排除规则（预计过滤50-100条）**

当前问题：大量非影像检查被误标为影像检查模态。

**实施步骤：**

1. **医嘱清洗规则扩展（preprocess_service.py）**
   ```python
   # 在 SPECIAL_ITEM_MARKERS 中增加
   NON_IMAGING_MARKERS = {
       '心电图', 'ECG', 'EKG', '脑电图', 'EEG',
       '肌电图', 'EMG', '质谱', '基因', 'DNA',
       '串联质谱', '干血斑', '实验室', '检验'
   }
   ```

2. **模态校验逻辑（orchestrator.py）**
   ```python
   # 检测到 XR/DR 模态 + 非影像关键词 → 标记为 unmatchable:non_imaging
   if modality in ('XR', 'DR') and any(m in record for m in NON_IMAGING_MARKERS):
       return _empty_result(record, tier='none', reason='non_imaging')
   ```

**目标过滤项目：**
- X线干血斑串联质谱检测
- X线心电图(24小时动态心电图)
- X线 12导联心电图(动态监测)
- DR 脑电图监测

**预期效果：**
- 减少词库缺项误报50-100条
- 提升未匹配原因分类准确性

---

**B2：介入治疗识别规则（预计标注100-150条）**

当前问题：大量DSA介入操作无法识别为"不应匹配"类别。

**实施步骤：**

1. **介入操作标记词扩展**
   ```python
   # constants.py
   SPECIAL_ITEM_MARKERS.update({
       '栓塞术': 'intervention',
       '支架置入': 'intervention',
       '溶栓': 'intervention',
       '取栓': 'intervention',
       '球囊扩张': 'intervention',
       '导管': 'intervention',  # 谨慎使用，需配合上下文
   })
   ```

2. **DSA模态特殊处理**
   - 关键词引擎（us_spect_pet_matcher.py）中增加 DSA 介入词表
   - 命中介入词时返回 `unmatchable:intervention`

**目标识别项目：**
- DSA经导管动脉栓塞术
- DSA腹主动脉-髂动脉支架置入术
- DSA溶栓/取栓
- DSA支气管动脉栓塞术

**预期效果：**
- 正确识别100-150条介入操作为"不应匹配"
- 降低词库缺项误判率

**B3：口腔专科检查处理（预计标注10-20条）**

当前问题：口腔专用CBCT、全景片等被误判为缺项。

**实施步骤：**

1. **口腔检查标记**
   ```python
   SPECIAL_ITEM_MARKERS.update({
       '根尖片': 'dental',
       '全景片': 'dental',
       '曲面体层': 'dental',
       '口内': 'dental',
   })
   ```

2. **CBCT模态独立处理**
   - 在 orchestrator.py 中将 CBCT 归为不支持模态
   - 或创建独立的口腔影像规则引擎

**预期效果：**
- 减少10-20条口腔检查的误判
- 为未来扩展口腔影像支持预留接口

---

**B4：多模态组合医嘱拆分（预计解析5-10条）**

当前问题：`CT/MRI/PET-CT(化疗前基线)` 无法正确解析。

**实施步骤：**

1. **预处理阶段识别多模态组合**
   ```python
   # preprocess_service.py
   MULTI_MODALITY_PATTERN = re.compile(r'(CT|MR|PET-CT|US)/(CT|MR|PET-CT|US)')
   
   if MULTI_MODALITY_PATTERN.search(record):
       # 拆分为独立子项：CT(...) + MR(...) + PET-CT(...)
       modalities = extract_modalities(record)
       base_content = remove_modality_prefix(record)
       return [f"{mod} {base_content}" for mod in modalities]
   ```

2. **递归匹配各子项**
   - 在 tokenizer_service 中分别处理各模态
   - 汇总结果时取并集

**预期效果：**
- 解析5-10条多模态组合医嘱
- 提升复杂医嘱的处理能力

### 方案C：不支持模态规范化（中长期）

**C1：IR（介入放射）模态整合**

**现状：** 126条IR记录未被处理。

**决策点：**
1. 介入放射是否应纳入匹配范围？
   - 若是：扩展DSA关键词引擎覆盖IR
   - 若否：统一标记为 `unmatchable:intervention`

2. IR与DSA的关系
   - IR是介入放射的通用代码
   - DSA是数字减影血管造影（介入的影像基础）
   - 建议：IR项目检查内容，有影像诉求的映射到DSA引擎

**实施建议：**
```python
# orchestrator.py
MODALITY_ALIAS = {
    'IR': 'DSA',  # 介入放射使用DSA引擎
    'XR': 'DR',   # X线平片使用DR引擎
}

if modality in MODALITY_ALIAS:
    modality = MODALITY_ALIAS[modality]
```

**预期效果：**
- 126条IR项目进入匹配流程
- 预计50-70%可匹配到标准DSA项目
- 剩余30-50%标记为介入操作（不应匹配）

---

**C2：OTHER/Other 模态细化**

**现状：** 478条记录（58.5%）被标注为OTHER/Other。

**分析策略：**
1. 导出 OTHER 模态的所有项目名称
2. 按关键词聚类：
   - 含"造影"、"CTA"、"增强" → 可能是特殊CT
   - 含"超声"、"彩超" → 应为US
   - 含"内镜"、"胃镜"、"肠镜" → 不应匹配
   - 含"手术"、"治疗" → 不应匹配

**实施步骤：**
```sql
-- 1. 导出OTHER模态项目进行人工审查
SELECT id, name_zh, body_part
FROM procedure_dictionary
WHERE modality IN ('OTHER', 'Other')
LIMIT 100;

-- 2. 按关键词重新分类
UPDATE procedure_dictionary
SET modality = CASE
    WHEN name_zh LIKE '%超声%' OR name_zh LIKE '%彩超%' THEN 'US'
    WHEN name_zh LIKE '%造影%' OR name_zh LIKE '%CTA%' THEN 'CT'
    WHEN name_zh LIKE '%内镜%' OR name_zh LIKE '%胃镜%' THEN 'ES'
    ELSE modality
END
WHERE modality IN ('OTHER', 'Other');
```

**预期效果：**
- 200-300条重新分类到正确模态
- 剩余100-200条确认为"真·其他"

## 四、实施路线图

### Phase 1：快速止血（1-2周）

**目标：** 降低误判率，提升未匹配原因分类准确性

1. ✅ 扩展 SPECIAL_ITEM_MARKERS（非影像、介入、口腔）
2. ✅ 优化未匹配原因分类逻辑
3. ✅ 运行全量匹配验证改进效果

**验收标准：**
- 词库缺项误报减少50%
- unmatchable 分类准确率 > 90%

### Phase 2：标准库补充（2-3周）

**目标：** 覆盖高频缺失项目

1. 补充复合增强方式（动静脉双期、CTA+CTV）
2. 补充特殊造影技术（直接造影、脊髓造影）
3. 补充血管专项成像标准项
4. 运行回归测试验证匹配率提升

**验收标准：**
- 标准库缺项减少60-80条
- 整体匹配率提升3-5%

### Phase 3：模态整合（3-4周）

**目标：** 扩大模态覆盖范围

1. IR模态映射到DSA引擎
2. OTHER模态重新分类
3. CT-DE、AN模态支持
4. 全量数据重新匹配与评估

**验收标准：**
- 不支持模态减少200条
- 整体匹配率提升5-8%

### Phase 4：词库深度优化（4-6周）

**目标：** 解决长尾问题

1. 多模态组合医嘱拆分逻辑
2. 消歧规则优化（降低ambiguous档）
3. 降级匹配规则调优（降低degraded档）
4. 性能优化与缓存策略

**验收标准：**
- exact + partial 档占比 > 70%
- ambiguous 档 < 5%
- 整体匹配率 > 85%

## 六、风险与注意事项

### 6.1 数据质量风险

**风险：** 源数据本身存在模态标注错误。

**缓解措施：**
- 建立模态校验规则
- 人工抽样审核OTHER模态数据
- 提供数据纠错反馈机制

### 6.2 过度匹配风险

**风险：** 为了提升匹配率，错误匹配不应匹配的项目。

**缓解措施：**
- 严格定义 unmatchable 规则
- 保持 exact 档的高精度要求
- 建立匹配结果人工审核流程

### 6.3 性能影响

**风险：** 规则复杂化导致匹配速度下降。

**缓解措施：**
- 优先使用L1缓存（match_cache表）
- 关键词预编译与索引优化
- 批量匹配时使用异步处理

### 6.4 维护成本

**风险：** 规则过多导致维护困难。

**缓解措施：**
- 规则代码模块化
- 完善单元测试覆盖
- 建立规则变更影响分析机制
