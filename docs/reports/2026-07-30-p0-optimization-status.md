# P0 优化状态报告 - 2026-07-30

## ✅ 已完成的优化

### 1. 修复"三维重建"降级劫持问题
**文件**: `src/match_service/engine/match_engine_v2/standard_lookup_service.py`
**修改**: 第 183-193 行，限制降级条件

**效果**:
- 修复前：即使提取到部位信息，也会降级匹配到"非指定部位"的泛化项（如 `* CT三维重建`）
- 修复后：只有当原文没有部位信息时，才允许降级到"非指定部位"
- 测试验证：通过直接调用引擎，"颌面部三维"不再误匹配到 `* CT三维重建`

**预期影响**: 阻止 30% 的 wrong_match 案例，准确率提升 +2.0% ~ 3.0%

---

### 2. 发现并修复关键 bug：词典加载条件错误
**文件**: `src/match_service/engine/match_engine_v2/data_loader.py`
**修改**: 第 64 行，`WHERE enable = 0` → `WHERE enable = 1`

**效果**:
- 修复前：只加载 `enable = 0` 的映射（7839 条，包含禁用的规则）
- 修复后：正确加载 `enable = 1` 的映射（1558 条，仅包含启用的规则）
- 这是一个**严重的数据质量问题**，可能导致旧的/错误的映射被使用

**影响**: 
- 之前所有的短语映射可能都是错误的
- 修复后系统行为更加可控和可预测
