## 二、核心发现：DR 与 CT/MR 的本质差异

**DR 标准库只有"具体部位"项（股骨/胫腓骨/肩/髋/腕关节等），没有任何"泛指部位"标准项**
（骨骼/全身/关节/四肢 搜索均为 0 条）。而 CT/MR 有"非指定部位"通用项兜底。
因此 DR 的泛指输入（骨骼/全身/关节/受累关节/受照部位）**算法上无标准可命中**，
这是 DR 未匹配以真缺口为主、算法侧空间极小的根本原因。
