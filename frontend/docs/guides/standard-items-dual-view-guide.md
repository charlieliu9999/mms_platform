# 标准项目页面使用指南

## 🎯 新功能：双视图模式

标准项目页面现在支持**简化视图**和**完整视图**两种模式，一键切换！

---

## 📖 使用方法

### 1. 访问标准项目页面

点击左侧导航栏的 **"标准项目"** 进入页面。

### 2. 切换视图模式

在页面顶部找到视图切换按钮：

```
┌─────────────────────────────────────┐
│ 🔘 简化  🔘 完整   选择标准版本: ▼  │
└─────────────────────────────────────┘
```

**简化视图** (默认) - 适合日常浏览
- 显示6个核心字段
- 表格紧凑，易于快速扫描

**完整视图** (专业) - 适合详细管理
- 显示11个完整字段
- 包含三级部位、摆位、范围等专业信息
- 支持横向滚动查看所有列

## 🖱️ 操作技巧

### 横向滚动（完整视图）

完整视图会显示提示：
```
💡 完整视图显示所有字段，支持横向滚动
```

- **鼠标滚轮** - 按住 `Shift` 键 + 滚动鼠标轮
- **触控板** - 双指左右滑动
- **滚动条** - 使用表格底部的横向滚动条

**固定列**: 编码和名称两列固定在右侧，横向滚动时始终可见。

### 筛选和搜索

两种视图模式下，所有筛选功能都正常工作：

- **模态筛选** - 点击模态卡片快速筛选
- **版本筛选** - 选择特定规则版本
- **关键词搜索** - 搜索编码或名称
- **重置** - 一键清除所有筛选条件

### 分页浏览

- 默认每页显示 20 条记录
- 切换视图模式时，当前页码保持不变
- 筛选条件改变时，自动回到第1页

## ❓ 常见问题

### Q1: 完整视图中某些字段显示 "-"，为什么？

**A**: 这是正常的。部分字段在数据库中可能为空：
- 早期版本的标准项目可能缺少三级部位、摆位等字段
- 简单检查（如常规平扫）可能没有复杂的摆位要求
- 数据正在逐步完善中

### Q2: 切换视图后，我的筛选条件会丢失吗？

**A**: 不会！所有筛选条件（模态、版本、搜索关键词）在切换视图时都会保留。

### Q3: 可以保存我偏好的视图模式吗？

**A**: 当前每次访问页面都会默认显示简化视图。如果需要持久化偏好设置，请联系开发团队。

### Q4: 移动端可以使用完整视图吗？

**A**: 可以，但建议在移动设备上使用简化视图以获得更好的体验。完整视图在小屏幕上需要频繁横向滚动。

### Q5: 为什么词库治理台中没有"标准参考字典库"了？

**A**: 该功能已整合到独立的"标准项目"页面中。现在只需访问一个页面，通过切换视图模式即可查看不同详细程度的数据。
