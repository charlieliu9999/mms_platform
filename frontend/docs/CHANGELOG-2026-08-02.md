# 更新摘要 - 标准项目页面双视图增强

**日期**: 2026-08-02  
**类型**: 功能增强  
**版本**: v1.1.0

---

## ✨ 新功能

### 双视图模式切换

标准项目页面现在支持**简化视图**和**完整视图**两种显示模式，用户可以一键切换：

- **简化视图** (默认) - 6个核心字段，适合日常浏览
- **完整视图** (专业) - 11个完整字段，包含三级部位、摆位、范围等专业信息

---

## 🎯 解决的问题

✅ **消除功能重复**  
之前"标准项目"页面和"词库治理台→标准参考字典库"显示相同数据，造成用户困惑和维护成本增加。

✅ **满足不同用户需求**  
- 业务用户：使用简化视图快速查找
- 专业用户：使用完整视图进行详细管理

✅ **提升数据可见性**  
完整视图新增显示：三级部位、摆位、范围等重要医学标准字段

## 🎮 如何使用

1. **访问页面**  
   点击左侧导航 "标准项目" 或直接访问 `http://localhost:3100/standard-items`

2. **切换视图**  
   页面顶部找到切换按钮：
   ```
   🔘 简化  🔘 完整
   ```

3. **横向滚动**（完整视图）  
   - 按住 `Shift` + 鼠标滚轮
   - 触控板双指左右滑动
   - 使用底部滚动条

## ⚠️ 注意事项

### 后端数据验证

完整视图显示的 `position` 和 `scope` 字段需要后端API支持。请验证：

```bash
# 测试API返回
curl 'http://localhost:9100/api/admin/standard-items?page=1&page_size=5' | jq '.data[0]'
```

**预期字段**:
- `position` - 摆位
- `scope` - 范围

如果这些字段返回 `null` 或缺失，完整视图中会显示 "-"。

### 浏览器兼容性

- **固定列功能** 需要现代浏览器支持 (Chrome 90+, Firefox 88+, Safari 14+)
- 旧版浏览器中固定列会降级为普通列
