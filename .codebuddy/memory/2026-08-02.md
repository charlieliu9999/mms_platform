## 算法流程图梳理
- 应用户要求，完整梳理了医学影像检查项目匹配系统的算法流程
- 系统采用三层分派架构：L1 映射库缓存（SHA256 O(1)）→ L2 算法引擎（6步 NLP Pipeline）→ L3 LLM 语义兜底
- L2 Pipeline：预处理 → jieba 分词 → 正则模式匹配 → 实体提取（部位+扫描方式）→ 消歧 → 标准库查询+评分排序
- 评分维度：部位匹配(30) + 扫描方式(20) + 名称包含(15) + 关键词重叠(10) + 字符相似度(5)
- 分级：exact(≥80) / partial(≥50) / ambiguous(≥30) / none(<30)
- 自学习闭环：L2 失败项 → feedback 表 → L3 Agent 异步处理 → 高置信回写 L1
- 输出：algorithm-flowchart.html 可视化流程图
