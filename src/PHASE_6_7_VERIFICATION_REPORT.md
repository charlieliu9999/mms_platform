## 问题修复记录

### 问题 1: result_codes 字段不存在

**错误**:
```
asyncpg.exceptions.UndefinedColumnError: column "result_codes" does not exist
```

**原因**: `match_cache` 表没有 `result_codes` 字段，结果存储在 `result_json` 文本字段中。

**修复**: 修改 `_load_all_usage_stats` 方法，解析 `result_json` 提取标准项 code。

**提交**: `fix(phase7): 修复使用统计加载逻辑并添加综合验证脚本` (24f4f34)

### 问题 2: 变量名遮蔽

**错误**:
```python
UnboundLocalError: cannot access local variable 'text' where it is not associated with a value
```

**原因**: 循环变量 `text` 遮蔽了 SQLAlchemy 的 `text()` 函数。

**修复**: 将循环变量改名为 `check_text`。
