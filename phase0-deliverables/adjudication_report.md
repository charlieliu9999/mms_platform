## 二、phrase_map（95条）

### 2.1 prod_only 分析（54条）

#### 2.1.1 模态归一化规则（建议保留，18条）
生产环境将 MRI/核磁共振 等变体统一为标准术语：

```
MRI → 平扫
核磁共振 → 平扫  
核磁共振(MRI) → 平扫
核磁共振（MRI）→ MRI
磁共振(MRI) → 平扫
```

**裁定**: **KEEP ALL** - 这是生产环境经验总结的标准化规则

#### 2.1.2 位置/方位标准化（3条）
```
正侧斜 → 正侧斜 (normalize, enable=0)
正侧斜位 → 正、侧、斜位 (normalize, enable=0)
```

**裁定**: **DROP** - enable=0 且与本地规则冲突（见 2.2.1）

#### 2.1.3 解剖术语映射（8条）
```
肠系膜上动脉|肠系膜上静脉&肠系膜上动脉 → 肠系膜上动脉
输尿管膀胱 → 全泌尿系
双肾输尿管膀胱 → 全泌尿系
颈、胸、腰和尾椎 → 颈胸腰尾椎
```

**裁定**: **KEEP ALL** - 生产环境部位词归一规则

#### 2.1.4 血管相关（2条）
```
血管成像 → 血管血管成像 (pre, V3.7/V3.8)
```

**裁定**: **DROP** - 映射结果"血管血管成像"有重复词，疑似错误

#### 2.1.5 CT 特殊流程（2条）
```
低张平扫|增强 → 低张平扫+增强
低张平扫|平扫|增强 → 低张平扫+增强
```

**裁定**: **KEEP** - CT 肠道检查特殊流程

#### 2.1.6 DR/MR 专项规则（21条）

DR 规则（5条）:
```
全长正位|全长侧位 → 全长正、侧位
全长正位片 → 全长正位
膀胱 → 膀胱区
```
**裁定**: **KEEP ALL**

MR 规则（16条，主要是血管成像缩写）:
```
(血管) → (空)
动脉高分辨磁共振血管成像(HRMRA) → HRMRA
```
**裁定**: **KEEP ALL**

### 2.2 local_only 分析（41条）

#### 2.2.1 位置标准化冲突（5条）

本地规则将"正侧斜位"展开为"正、侧、**双斜**位"，而生产为"正、侧、斜位"：

```
正侧斜 → 正、侧、双斜位 (V3.8)
正侧斜位 → 正、侧、双斜位 (V3.7/V3.8)
```

**裁定**: **USER_DECIDE** - "双斜位"是两个斜位（left oblique + right oblique），还是"斜位"就够了？需用户确认医学规范。

#### 2.2.2 扫描术语标准化（4条）
```
常规扫描 → 平扫
普通扫描 → 平扫
薄层普通扫描 → 平扫
```

**裁定**: **KEEP** - 补充生产缺失的同义词映射，enable=0 表示规则存在但未激活，保留备用

#### 2.2.3 CT 部位标准化（32条）

全部为 modality=CT, step=normalize, version=V3.8.2, enable=0:

```
冠状动脉 → 冠状动脉
冠脉 → 冠状动脉
副鼻窦 → 副鼻窦
双眼 → 眼部
垂体 → 鞍区
... (共32条)
```

**裁定**: **KEEP ALL** - 这是本地引擎的部位词归一层，虽然 enable=0 但是重要的医学知识库，应合并到生产

## 三、ambiguity（71条）

### 3.1 prod_only（71条）- 全部建议保留

所有条目均为生产环境的消歧规则，enable=1（启用中），涵盖：

- **CT 消歧**（50条）：any→具体部位、冠状动脉→冠脉、肺结节分析 等
- **MR 消歧**（18条）：血管成像、脑部、颈部 等  
- **DR 消歧**（3条）：胸部、腹部 等

**示例**:
```
(CT, any, 肺结节分析) → (胸部, 肺结节分析)
(CT, 冠状动脉, 钙化积分) → (冠脉, 钙化积分)
(MR, any, 血管成像) → (颅脑, 血管成像)
```

**裁定**: **KEEP ALL** - 消歧规则是匹配准确性的核心，生产规则应全部继承
